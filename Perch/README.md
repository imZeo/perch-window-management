# Perch

Perch is a macOS menu bar app for assigning apps to Spaces and reopening or launching them on the right desktop with a single action.

## What Perch Does

- Lists regular running apps in a menu bar dropdown
- Assigns app bundle IDs to desktop numbers 1 through 9
- Saves rules locally in Application Support
- Reopens running apps on their assigned desktop
- Launches saved apps on their assigned desktop even when they are not running
- Optionally watches app launches and reapplies assigned desktops automatically
- Provides an in-app diagnostics panel for recent Perch activity

## Current Design

Perch is an AppKit menu bar utility, not a document app.

- The status item shows running apps and saved rules
- Running app submenus let you assign or clear desktop mappings
- Saved rule submenus let you launch or reopen apps on their assigned desktop
- A settings window exposes Perch’s behavior and saved rules
- A diagnostics window shows recent info and error events generated by Perch

## Settings

Perch currently supports these persisted settings:

- `Max desktops shown`
- `Shortcut assumptions`
  - `Control + Number`
  - `Option + Number`
  - `Command + Number`
- `Launch delay`
- `Watch launches and reopen assigned apps`
- `Launch Perch automatically when you log in`

## How Desktop Switching Works

Perch switches desktops by posting a synthetic modifier-plus-number keyboard shortcut, then waits for the configured launch delay before activating or launching the target app.

That means:

- your Mission Control shortcuts for `Switch to Desktop 1...9` must exist
- the configured shortcut assumption in Perch must match your actual macOS shortcut setup
- Perch needs Accessibility permission to post the shortcut events

## Diagnostics

Perch records a rolling in-app diagnostics log for:

- rule changes
- launch and activation attempts
- desktop switching attempts
- settings updates
- launch-watch activity
- launch failures and permission issues

## Current Limits

Perch intentionally does not do these things yet:

- detect the real number of Spaces dynamically via private APIs
- move windows between desktops
- perform deep UI automation in Mission Control
- guarantee background-only enforcement without visible focus changes

## Notes

- Perch is configured as a UI agent menu bar app.
- Perch should not run with App Sandbox enabled because desktop switching relies on synthetic input and Accessibility access.
- `Watch launches` is intentionally optional because it can pull focus to another desktop when a matched app launches.
